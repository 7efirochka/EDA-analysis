# Комплексный EDA

**analysis.ipynb** - ноутбук с исследованием датасета. Анализ воронки продаж и поведения пользователей интернет-магазина за октябрь-декабрь 2019.

Загрузка датасета -> базовая обработка -> построение графиков -> практические выводы для бизнеса.

# Датасет

[eCommerce Events History in Cosmetics Shop](https://www.kaggle.com/datasets/mkechinov/ecommerce-events-history-in-cosmetics-shop?select=2019-Oct.csv)

# Стек

Python, Pandas, Matplotlib, Seaborn, Jupyter Notebook

# Что исследовалось

- Воронка и конверсия (view -> cart -> purchase) по месяцам
- Средний чек по месяцам
- Распределение уникальных пользователей по месяцам
- Распределение количества совершенных покупок по времени суток
- Топ-10 категорий по выручке

# Ключевые выводы

**Воронка продаж.** Конверсия View -> Cart снижается с октября по декабрь, с 61% до 44% соответственно. Конверсия View -> Purchase варьируется в пределах ~15%, что является показателем эффективной работы сайта или маркетинговой стратегии. Пик конверсии Конверсия View -> Purchase приходится на декабрь (18%), что вероятно связано с зимними праздниками. Ключевая проблема - незавершенные покупки, 45-60% пользователей удаляют товар из корзины, не совершив покупку.

**Средний чек** за весь рассмотренный период составляет 4.9$. Пик приходится на декабрь (>5$), вероятно из-за частых покупок перед зимними праздниками. Стоимость среднего чека варьируется в пределах ~0.20$.

**Количество уникальных пользователей в течении месяца.** Большое количество пользователей в начале октября сложно объяснить без дополнительных данных, сезонных поводов к покупкам в этот период нет. Пики в конце ноября связаны с Чёрной пятницей. Спад пользователей в конце декабря, вероятно, связан со снижением пользовательской активности в период зимних праздников.

**Количество совершенных покупок от времени суток.** Пользователи наиболее активны в рабочее время (утро-день). Но 1/5 всех покупок совершается вне рабочего времени или ночью.

**Категории товаров.** Две лидирующие категории дают ~37% всей выручки, топ-3 категории — около 50%. Остальные 7 категорий из топ-10 распределены равномерно, в диапазоне 5.8–8.5% каждая.

# Бизнес рекомендации

- Сфокусировать маркетинговые рассылки в промежутке 7:00 - 18:00, когда активность у пользователей максимальная.
- Уделить внимание топ-3 категориям, которые приносят наибольшую выручку при планировании закупок.
- Исследовать причины высокой пользовательской активности в начале октября, при закупке нужных категорий товара может принести большую выручку.
- Исследовать причины большого количества брошенных корзин (45-60%), возможно требуется упрощение процесса покупки.
